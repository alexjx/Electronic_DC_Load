# Electronic Controlled DC Dummy Load

This is a electronic controlled DC dummy load based upon Arduino.
Following components are used:
* AD7199 for ADC
* AD5541 for DAC
* IRF250n
* ATMega328P-AU

The input is based upon rotary encoder
